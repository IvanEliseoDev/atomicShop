# atomicShop
This project consists of a robust digital solution designed for the marketing of chemical equipment and reagents, optimized for legal compliance and multi-site management.

he project is developed using the MERN stack (MongoDB, Express, React, Node.js) and TypeScript throughout the ecosystem to ensure data integrity and facilitate maintenance.

Main Modules
E-commerce (Frontend): Intuitive interface with a catalog categorized by risk levels and technical regulations. Includes a shopping cart, order tracking, and customer profiles.

Administrative Management (Dashboard): Centralized control panel for managing shared inventory across multiple physical branches.

Specialized Billing: Automated system for issuing tax credits (B2B), integrating tax calculations, and validating tax records.
